# Navegació en cinc pàgines

Actualització preparada el 23 de novembre de 2026 a partir del repositori públic crp-badalona/pensament.

## Menú compartit

1. Inici → index.html: bloc «Comencem?», presentació «Rutines i destreses de pensament», conceptes, diferències, exemples interactius per etapes, primers passos i accés als altres apartats. El botó inicial baixa a l’explicació dins de la mateixa pàgina.
2. Caixa d’eines. Explora el catàleg → caixa-eines.html: «Fem visible el pensament», botó «Explora el catàleg», «Què vols fer pensar?» amb sis botons i «Explora les propostes» amb cerca, filtres i fitxes.
3. Documentació i bibliografia → documentacio.html: vídeos, documents, webs i bibliografia. La part conceptual és a Inici.
4. Autors i fonts → autories.html: registre d’autoria, referents i condicions dels materials.
5. Sobre el projecte → sobre.html: finalitat i orientacions generals del projecte.

El menú és el mateix a totes les pàgines i marca l’apartat actiu. En pantalles estretes es distribueix en files.

## Recórrer el catàleg

A Caixa d’eines, el botó «Explora el catàleg» porta al bloc que reuneix «Què vols fer pensar?» i les propostes. Els sis botons seleccionen la finalitat i porten directament als resultats filtrats. «Neteja filtres» recupera totes les propostes. Les fitxes mantenen els materials i les atribucions existents.

## Aplicar l’actualització

1. Descomprimeix aquest ZIP.
2. A https://github.com/crp-badalona/pensament, branca main, utilitza Add file → Upload files.
3. Arrossega el contingut del ZIP conservant les carpetes i substitueix els fitxers amb el mateix nom. Afegeix els fitxers nous.
4. Fes Commit changes i espera que GitHub Pages acabi el desplegament.
5. Obre el web i recarrega amb Ctrl+Shift+R. Recorre els cinc apartats, una de les sis finalitats i una fitxa.

Aquest ZIP conté només els fitxers nous o modificats. Necessita la resta del web existent. No buidis el repositori ni la carpeta materials.

No cal modificar Google Sheets, l’Excel mestre, l’Apps Script ni tornar a publicar les dades. No se substitueixen data/catalog.json, les URL oficials ni els PDF.

## Compatibilitat d’enllaços

Els enllaços antics index.html#cataleg i index.html#fitxa-ID redirigeixen al nou espai del catàleg. comencem.html redirigeix a Inici per als conceptes i exemples, i a Documentació i bibliografia per als vídeos, recursos i bibliografia, mantenint l’àncora i els paràmetres. Els exemples d’aula i les interpretacions ja apunten directament a la nova ubicació de les fitxes.

## Comprovació

Proves superades de les cinc pàgines i l’ordre del menú, estat actiu, rutes antigues, sis finalitats amb filtratge de les dades, neteja de filtres, obertura de fitxes, exemples per etapes, separació dels blocs d’Inici i Documentació, vídeos i les 16 regles de publicació.
